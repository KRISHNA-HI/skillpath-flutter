# SkillPath – Flutter

A mobile learning and opportunity discovery application designed to help learners discover relevant programs and allow admins to manage learning opportunities.

## Project Vision

SkillPath aims to provide a simple mobile platform where learners can discover learning opportunities, view program details, save programs, and apply to relevant opportunities. Admins can manage and monitor available programs.

## Objective

The main objective of SkillPath is to create an easy-to-use mobile application that connects learners with relevant courses, workshops, volunteering programs, and other learning opportunities.

## Target Users

### Learner

- Discover learning opportunities
- Search and filter programs
- View program details
- Save programs
- Apply for opportunities
- Manage profile

### Admin

- View and manage opportunities
- Add new opportunities
- Monitor active and expired programs
- Manage program information

## Key Features

### Learner Features

- Login and account creation
- Learner home dashboard
- Search opportunities
- Category-based discovery
- Program listing
- Program details
- Save programs
- Apply for programs
- Profile management

### Admin Features

- Admin dashboard
- Opportunity statistics
- Add opportunity
- Manage recent opportunities
- View active and expired programs

## Navigation Flow

### Learner Flow

Login  
→ Learner Home  
→ Discover / Program Listing  
→ Program Details  
→ Apply / Save  
→ Profile

### Admin Flow

Admin Login  
→ Admin Dashboard  
→ View Programs  
→ Add / Manage Opportunity  
→ Program Details
